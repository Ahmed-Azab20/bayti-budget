# بيتي | ميزانية البيت

واجهة عربية RTL لإدارة مصاريف البيت، مبنية بـ React وVite وTailwind CSS. التطبيق يعمل بأسلوب **Offline-first**؛ البيانات المحلية تُحفظ داخل IndexedDB عبر Dexie، لذلك يمكن تسجيل المصاريف بدون اتصال بالإنترنت.

## ما تم تنفيذه

تشمل النسخة لوحة ملخص للمتبقي والدخل والمصروف، تسجيل مصاريف ودخل وأهداف مالية، تعديل وحذف العمليات، تاريخ فعلي لكل عملية، بحث نصي، تصفية بالفئة أو نطاق التاريخ، وتقارير مبنية على البيانات المسجلة. كما تحتوي على وضع فاتح/داكن، صفحة دخول عربية بالبريد وحساب Google كواجهة تمهيدية، وتصدير واستيراد النسخ الاحتياطية.

من الإعدادات يمكن تصدير نسخة Word للمراجعة والطباعة أو Excel متعدد الأوراق يحتوي على العمليات والتقارير والفئات والأهداف. الاستيراد يعرض شاشة تأكيد قبل استبدال البيانات الحالية ويسترجع النسخة داخل معاملة Dexie واحدة.

## التشغيل محلياً

تحتاج إلى Node.js 20 أو أحدث وpnpm. بعد تنزيل المشروع شغّل:

```bash
pnpm install
pnpm dev
```

ثم افتح الرابط الذي يظهر في الطرفية. لفحص TypeScript أو إنشاء نسخة production:

```bash
pnpm check
pnpm build
pnpm start
```

صفحة الدخول موجودة على `/login`، بينما التطبيق الرئيسي على `/`.

## التشغيل المجاني على الإنترنت

لأن الواجهة الحالية static ولا تحتاج خادماً خاصاً، يمكن نشرها مجاناً على GitHub Pages أو Netlify أو Vercel. اربط مستودع GitHub، اختر أمر البناء `pnpm build`، ومجلد النشر `dist/public` إذا كان المضيف يطلب مجلد إخراج. لا ترفع مجلد `node_modules` ولا أي مفاتيح سرية.

## ملاحظات مهمة

إعدادات Firebase ومعرّف الأسرة مضمّنة داخل `client/src/lib/cloud.ts`، لذلك يبدأ التطبيق المزامنة تلقائياً مع مساحة `azab-family` ولا يعتمد على `localStorage` لإعدادات الاتصال. Firestore يزامن العمليات والدخل والأهداف والأفراد والفئات، بينما يظل Dexie كاشاً محلياً للعمل أوفلاين. قبل الاستخدام الحقيقي، فعّل مصادقة Firebase وقواعد Firestore المقيدة بالمستخدم؛ لا تترك قاعدة البيانات مفتوحة للعامة.

بيانات Dexie مرتبطة بالمتصفح والجهاز، لكن عند توفر الإنترنت تتم مزامنتها تلقائياً مع Firestore. استخدم تصدير Excel من الإعدادات للاحتفاظ بنسخة إضافية ونقل البيانات إلى جهاز جديد.

## التقنية

React 19، TypeScript، Vite، Tailwind CSS، Lucide Icons، Sonner، Dexie/IndexedDB، Firebase Firestore، وSheetJS/XLSX.
